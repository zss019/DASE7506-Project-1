# Course GitHub issue (score submission)

GUIDE: before the score deadline, submit **student ID** and **full-test BPB** on the [course website](https://xudongwu-0.github.io/courses/dase7506/). The site **generates** a GitHub issue; you must **confirm it on GitHub** with the same account you will use for later link updates. Links are optional for this step and required by 30 September.

This repository cannot finish that click: the issue must be opened as **your** GitHub user in `xudongwu-0/xudongwu-0.github.io`.

## Values to enter on the form

| Field | Value |
|---|---|
| Student ID | *your university student ID* |
| Score BPB | **1.48544** |
| Code link | leave empty for now (optional until 30 September) |
| Checkpoint link | leave empty for now |
| Consent | check the publication box |

Use five decimal places as the leaderboard does (`toFixed(5)`). The scorer JSON is `1.485441599903059`.

## Steps

1. Open https://xudongwu-0.github.io/courses/dase7506/ while logged into GitHub in the same browser if possible.
2. Fill Student ID and **1.48544**. Leave both links blank unless the public repo and checkpoint URL already exist.
3. Tick the consent checkbox.
4. Click **Prepare score submission ↗**.
5. Click **Submit on GitHub ↗**. Do **not** edit the JSON in the issue body (`Keep the JSON unchanged`).
6. Create the issue. After a few minutes it should appear on the leaderboard as *Self-reported*, *Links pending*, with BPB **1.48544**.
7. Use that **same GitHub account** when you later submit the two HTTPS links.
